# ABI-028 implementation-guide

## Frozen scope

- Ordinary non-boss TTK composition after ABI-020 closure. Do not change boss cadence, boss identity, Golden scheduling, audio, visuals, or save schema.
- Reuse the ABI-020 production-path simulator and accepted elapsed-time/economy report. No second formula runner or render-time randomness.
- Produce one frozen TTK-band contract that ABI-029 consumes before affinity stats are introduced.

## Implementation sequence

1. Refresh ABI-020 evidence and freeze reference builds, stages, metrics, persistence class, and exclusions.
2. Run the baseline manual/automatic/combined matrix and trace the shared health/grade/family/modifier/selection owners.
3. Define and simulate a bounded candidate set with explicit fast, medium, durable, one-hit, several-hit, and near-ten-hit targets.
4. Select one measured model, record rejected alternatives and rollback, then change only its centralized production owner.
5. Regenerate stage receipts and add deterministic composition, boundary, reward, finite-value, boss/Golden exclusion, and historical-save regressions.
6. Add browser fixtures for representative bands, run `pnpm check`, then complete independent review, independent QA, verification, deployment, and Manager closure as separate managed steps.

## Verification matrix

- **Unit/domain:** deterministic composition, threshold boundaries, promotions, finite limits, boss/Golden exclusions, and unchanged reward ownership.
- **Simulation/integration:** manual-only, auto-only, combined, exact/event-jump equality, early/mid/late/long-run bands, walls, upgrades, and current/V1-V4 reload.
- **Browser/deployed:** visible representative fast/medium/durable sequences on desktop and narrow layouts with exact-SHA Pages evidence.
