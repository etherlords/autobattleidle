# ABI-036 implementation-guide

## Frozen scope

- Research four existing-platform options, select the minimum per semantic need, then ship scratches plus two useful surface treatments. No generic material framework or external CDN.
- Wait for ABI-029 because final family/affinity geometry and identity are inputs. Preserve legacy variants and all current unit/battlefield ownership.
- Any bitmap has a license manifest; procedural output has bounded resolution, deterministic inputs, cache policy, and disposal.

## Implementation sequence

1. Add a test-lab-only comparison fixture for DecalGeometry, CanvasTexture, UV/material map, and overlay mesh on rigid and deforming families.
2. Capture all-angle/animation images and resource/build measurements; document accepted/rejected techniques and budgets.
3. Add the smallest family-owned semantic surface spec and deterministic selection path.
4. Implement scratches and two approved treatments, including one animated body and one affinity-ready boss/ordinary case.
5. Test cache identity, finite transforms, z-fighting tolerance, replacement, reduced motion, and exact resource disposal.
6. Complete independent review/QA, Vault decision update, `pnpm check`, and exact-SHA deployment proof.

## Verification matrix

- **Research:** side-by-side all-angle/animation quality, draw calls, triangles, texture memory, creation/disposal time, build bytes, and mobile compatibility.
- **Unit/integration:** deterministic selection, semantic placement, bounds, color space/filtering, cache reuse, invalid input, replacement, and disposal with no save change.
- **Browser/deployed:** rigid/deforming/affinity cases, orbit and narrow framing, reduced motion, long replacement resource counts, no z-fighting/inside geometry, clean console, exact SHA.
